# Combine NYC ArcGis map of known lead service line locations and self-analyzed data of water tank inspection reports to create an interactive webpage for New Yorkers to assess their drinking water contamination risk.

## [Original webpage](http://tapwaterinteractive.dataprojects.lizziewalsh.com/)
## Final version [embedded here](https://www.thecity.nyc/2025/08/25/lead-water-pipes-test-kits-environmental-protection/) in _THE CITY_ September 2025 data investigation.

Methodology overview: Data used is publicly available and was last updated May 2025. Tank and service line data was analyzed, cleaned, and coded by Lizzie Walsh into the webpage using Python and Javascript. Lead service ArcGis geolocation data was pulled from [this map's](https://nycdep.maps.arcgis.com/apps/View/index.html?appid=fe8c7a4dd6d24959ac765660ba3a7c1a) feature layer using a Node.js.
